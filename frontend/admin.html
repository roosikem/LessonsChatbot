Each column gets a role. context columns become filters and "why relevant" reasons; a new context column is a new dimension, no code change. Personal data defaults to ignore. ranking columns (ratings, scores, dates) are stored as named signals; new ones don't change the ranking until a weight is set in the mapping. A title column is optional. A column whose values name items of a context source (e.g. projects) is detected and gets that source's lesson column, so "comparable" works.
